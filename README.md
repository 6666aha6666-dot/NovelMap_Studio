# NovelMap Studio (小说世界观坐标地图工作台)

> **专为小说创作者与世界观架构师打造的数字化空间坐标工作台。**  
> 摒弃传统纯视觉手绘地图易失真、无法计算的痛点，确立轻量级**平面笛卡尔坐标系统 (以 km/华里/海里/AU 为单位)**，支持大模型（LLM）一键生成世界观地图、PS 级图层可视化、画布手绘与微调、双向数据互通，以及无视觉完全可读的纯文本空间拓扑分析。

---

## 🌟 核心特性

- 🎯 **数学级精确坐标与零幻觉**：采用欧几里得平面直角坐标系，将复杂的奇幻/架空世界解构为结构化的【点（据点/城邦）、线（折线走向）、面（多圆拟合包络）】，方便大语言模型进行高精度方位推演、行军天数计算与点到线垂距判定。
- 🤖 **大模型极简闭环直连**：兼容所有 OpenAI 规范的 API 接口（如 DeepSeek、Kimi、通义千问 Qwen、GPT-4o、Claude 等），顶部一键输入需求，内置流光进度条与 4 阶段文学化状态反馈，生成即自动渲染。
- 📑 **PS 级图层管理器**：国家疆域、自然地貌、水系湖泊、山脉天险、主干路线、城镇聚落、世界奇观分层管理，支持独立一键眼睛开关显隐与全要素快速双击平移定位。
- 🌐 **多圆拟合面状地貌**：沙漠、雪原、湖泊与平原支持直接拖拽圆心平移，按住圆边缘手柄实时拉伸缩放半径，更支持【➕ 追加子圆】无缝拼接连绵不规则的大型复杂地貌。
- 📊 **纯文本空间拓扑报告**：后台内置几何空间分析引擎，一键输出精准文字报告（如 *“【风语镇】距【天水河】1.2km，地处【翡翠大平原】内，向东南78km为【赤阳沙城】”*），直接投喂大模型即可开始严密的小说行记与剧情撰写。
- 💾 **全套双轨存档系统**：每秒自动静默保存至本地浏览器 LocalStorage，防止意外关闭网页丢失劳动成果；支持导出为 `.novelmap.json` 文件或从电脑本地导入地图。

## 🚀 快速上手

### 方式一：直接网页运行（零安装）
直接双击打开项目中的 **`NovelMap_Studio.html`** 即可在任意现代浏览器（Chrome、Edge、Firefox 等）中使用。

### 方式二：一键全自动启动（推荐）
双击运行 **`一键启动工作台.bat`**：
1. 自动在后台准备轻量本地 API 跨域中转服务；
2. 自动在系统默认浏览器中打开工作台；
3. 控制台窗口将在 3 秒后自动隐退，直接开始创作。
