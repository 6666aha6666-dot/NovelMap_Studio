# 小说世界观地图空间坐标协议（Novel World Map Coordinate Protocol, NWM-CP v1.0）

## 1. 核心设计理念
本协议是专为大语言模型（LLM）与小说创作者设计的**数学/文本级地理空间协议**。
它摒弃了易失真的纯视觉图像，采用 **欧几里得平面直角坐标系（笛卡尔坐标系，单位：公里 km）**，将架空世界解构为结构化的【点、线、面（圆形拟合）】，支持高精度的几何距离、相对方位、点到线垂距计算与地缘推演。

---

## 2. 坐标系统约定
1. **原点 (0, 0)**：世界中心或世界观枢纽（如中央圣城、大陆交界处）。
2. **方向轴**：
   - X 轴：向东为正（+km），向西为负（-km）。
   - Y 轴：向北为正（+km），向南为负（-km）。（注意：数学直角坐标系，北为+Y，南为-Y）。
3. **距离与方位计算约定**：
   - 两点间直线欧氏距离：$D = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$
   - 点 $P(x_0, y_0)$ 到折线段 $AB$ 的最短距离（垂线/端点距）：用于判断“沿河分布的聚落”或“距主干商道多远”。
   - 方位角：以正北（+Y）为 0°，顺时针旋转，计算各地点间的精确方位（东北、西南等）。

---

## 3. 三大基本要素模型

### (1) 点状要素 (Points)
适用于：城市 (city)、小镇/村庄 (town/village)、堡垒关隘 (fort)、神秘奇观 (landmark)、宗门/遗迹 (ruin)。
```json
{
  "id": "city_01",
  "category": "point",
  "type": "city",
  "name": "极北凛冬城",
  "coord": [-35.0, 120.5],
  "desc": "北境寒铁领主统治的雄伟雪城，高墙由玄冰与花岗岩筑成。",
  "faction": "北境公国"
}
```

### (2) 线状要素 (Lines)
适用于：河流 (river)、山脉脊线 (mountain)、主要商道/行军路 (road)、边界线 (border)。
采用多关键控制点组成的折线段（折线各点顺序即代表水流流向或道路延展方向）。
```json
{
  "id": "river_01",
  "category": "line",
  "type": "river",
  "name": "苍蓝天河",
  "points": [
    [-60.0, 150.0],
    [-20.0, 90.0],
    [10.0, 40.0],
    [65.0, 10.0]
  ],
  "desc": "自北境雪山发源，向东南穿过中部平原的大陆第一水系。",
  "width_km": 1.5
}
```

### (3) 面状要素 (Regions / Areas)
适用于：湖泊 (lake)、内海/海洋 (sea)、大平原 (plain)、荒漠/戈壁 (desert)、永冻雪原 (snowfield)、密林 (forest)、国家疆域 (territory)。
**多圆包络拟合法（Multi-Circle Fitting）**：
为了方便大语言模型直接在纯文本上下文中读取并推演“某点是否在沙漠内部”，面状区域由一个或多个具有【圆心坐标 + 半径 (km)】的圆形集群拟合定义。
判定点 $P(x,y)$ 是否属于该区域：只需满足 $\exists i, (x-c_{x,i})^2 + (y-c_{y,i})^2 \le r_i^2$ 即可。
```json
{
  "id": "area_desert_01",
  "category": "area",
  "type": "desert",
  "name": "赤炎荒漠",
  "circles": [
    { "center": [80.0, -50.0], "radius": 45.0 },
    { "center": [120.0, -40.0], "radius": 35.0 }
  ],
  "desc": "极度缺水的狂风沙海，中心有流沙陷阱与上古遗迹。",
  "climate": "干燥酷热"
}
```

## 4. 图层系统定义 (Layer System)
每个要素分配图层，前端画板可随时独立隐藏或锁定：
1. `layer_territory`：国家疆域与势力范围面
2. `layer_terrain`：自然地貌面（平原、沙漠、雪原、森林）
3. `layer_waters`：水体面与线（河流、湖泊、海域）
4. `layer_mountains`：山脉与天险线
5. `layer_roads`：商道、航线、驿道
6. `layer_settlements`：城池、村落、关隘点
7. `layer_landmarks`：奇观、遗迹、宗门秘境点

---

## 5. 提示词标准协议（System Prompt 给大模型用）
大模型在输出此地图时，必须输出严格的 JSON 代码块或轻量 DSL，本应用可 100% 解析并映射到画布。
